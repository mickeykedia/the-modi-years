# Theme policy

Each action has exactly one primary theme for stable homepage placement and any number of cross-cutting tags for discovery.

Themes are editorial navigation, not judgements. Theme labels and colours must not imply approval or criticism.

Add or rename a theme only when:

- at least three actions need the category;
- its inclusion rule can be explained in one sentence; and
- it is meaningfully distinct from existing themes.

When an action spans themes, choose the theme most closely related to the government's primary mechanism and add the remaining concepts as tags. Record disputed reclassification through the normal proposal process.
