# Editorial methodology

This project records consequential actions by India's NDA-led Union governments from 2014 onward. It separates the factual record from an explicitly identified editor's value judgement.

An action is included when it materially changes law, administration, public expenditure, institutional practice, rights, or state capacity. Inclusion is not itself praise or criticism.

Every reviewed record must:

1. Identify the action, responsible institution, date, scope, and current status.
2. Separate official objectives, observable implementation, measured outcomes, and contested claims.
3. Cite sources at claim level, preferring legislation, judgments, official data, audits, and original research.
4. State uncertainty and meaningful disagreement.
5. Explain the values and affected groups behind the judgement.
6. Present the strongest reasonable countercase.
7. Preserve prior judgements and the reason for any revision.

The public site may show drafts, but drafts must be visibly distinguished from reviewed editorial records.
